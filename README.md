# 🎮 Rock Paper Scissors Web App

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.  
Play against the computer, test your luck, and enjoy the classic hand game right in your browser!

## 🚀 Features

- ✅ Player vs Computer gameplay <br>
- ✅ Randomized computer choices <br>
- ✅ Score tracking system <br>
- ✅ Simple animations & interactive buttons <br>
- ✅ Works on all modern browsers<br>

## 🛠️ Tech Stack

- **HTML5** – Structure of the game <br>
- **CSS3** – Styling and layout <br>
- **JavaScript (ES6)** – Game logic & interactivity <br>
